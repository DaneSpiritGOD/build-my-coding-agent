# My coding agent

This simple coding agent was created while I was learning how to build an agent with LLM SDK (Anthropic). It's purely handwritten in C#. The reason I chose C# is I am more familiar with C# than others. However, the programming language does not matter any longer in AI era.

The design of this agent is inspired by [ampcode-how-to-build-an-agent](https://ampcode.com/notes/how-to-build-an-agent).
